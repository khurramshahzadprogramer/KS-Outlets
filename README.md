# 🖤 KS OUTLETS — Premium Luxury E-Commerce ✨

A responsive luxury e-commerce storefront built as a single-page HTML, CSS, and JavaScript project. **KS OUTLETS** focuses on premium product presentation, smooth interactions, shopping-cart functionality, and a modern black-and-gold visual identity.

The project source defines the site as **“KS OUTLETS — Premium Luxury Lifestyle”** and presents curated products around modern minimalism and premium craftsmanship.

## ✨ Live Demo

🔗 **Website:** https://ksoutlets.netlify.app/

## 🛍️ Project Overview

KS OUTLETS is designed to feel like a modern premium online store. The storefront includes:

- 🏠 Hero section with collection-focused messaging
- 🎁 Limited-time 20% promotional offer
- 🗂️ Product categories
- ⭐ Featured products
- 🔥 Best sellers
- 🆕 New arrivals
- 💎 Brand / About section
- 💬 Customer testimonials
- 📩 Newsletter subscription UI
- 📞 Contact and social sections
- 📱 Responsive navigation and mobile menu
- 🛒 Shopping cart drawer
- 🤍 Product wishlist interactions
- 🔢 Product quantity controls
- ⚡ Product quick-add actions

The page includes categories for **Accessories, Clothing, Home & Living, and Electronics**.

## 🎨 Design & Visual Direction

The visual direction uses a premium luxury aesthetic built around:

- 🖤 Black / charcoal backgrounds
- ✨ Gold accent colors
- 🤍 White and off-white content areas
- 📰 Playfair Display for headings
- 🔤 Inter for body text
- 🪟 Rounded cards and modern shadows
- 🖱️ Hover states and micro-interactions
- 📐 Responsive layouts for different screen sizes

## ⚙️ Key Features

### 🛒 Shopping Experience

- 🖼️ Product cards with images, brands, ratings, prices, and availability
- 🏷️ Discount badges and new-product badges
- ⚡ Quick Add buttons
- 🤍 Wishlist buttons
- 🛍️ Cart drawer with quantity management
- 🗑️ Remove-item controls
- 💰 Dynamic cart totals

### 🧭 Navigation & UX

- 📌 Fixed responsive navbar
- 📱 Mobile slide-out menu
- 🔗 Smooth scrolling
- ✨ Scroll-based animations
- 📊 Responsive product/category grids
- ♿ Accessible focus states
- 🔔 Toast-style interaction feedback

### 🎁 Promotion

The storefront contains a promotional section advertising **20% off selected products** with the checkout code `WELCOME20`.

## 🧰 Technologies Used

- 🌐 **HTML5** — semantic page structure
- 🎨 **CSS3** — responsive styling, gradients, transitions, animations, and layout system
- ⚡ **JavaScript** — product rendering and interactive shopping features
- 🔹 **Font Awesome** — interface icons
- 🔤 **Google Fonts** — Inter and Playfair Display
- 🎬 **AOS (Animate On Scroll)** — scroll animations
- 🖼️ **Unsplash** — product and category imagery

## 📱 Responsive Design

The project is designed for desktop and mobile screens, with responsive grids, navigation, buttons, product cards, cart UI, and a dedicated mobile menu experience.
